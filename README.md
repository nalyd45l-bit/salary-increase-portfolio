# Мой вклад в LIFE PAY

Профессиональное интерактивное портфолио для обсуждения развития роли и условий оплаты. Доработка существующего репозитория `nalyd45l-bit/salary-increase-portfolio`.

Опубликованная версия: https://nalyd45l-bit.github.io/salary-increase-portfolio/

Изменения подготовлены в ветке `work/lifepay-portfolio-review`. Публикация не выполняется из этой ветки; Pull Request требуется проверить и слить отдельно. Настройки GitHub Pages и другие репозитории не изменены.

## Файлы и запуск

- `index.html` — всё содержание и реальные ссылки. Оно доступно без JavaScript.
- `styles.css` — единая система стилей, адаптивность и печать.
- `app.js` — меню, просмотр изображений, видео, навигация и подготовка PDF.
- `assets/` — официальный SVG LIFE PAY, сохранённый исходный PNG, скриншоты и оба исходных видео, а также оптимизированная общая анимация.
- [Отчёт об аудите и QA](docs/QA-REPORT.md).
- [Источники материалов и рыночных данных](docs/SOURCES.md).

Для сайта не нужны сборка, серверная часть, CDN или production-зависимости. Для локального просмотра достаточно статического сервера. Например, из корня репозитория:

```sh
python3 -m http.server 8080
```

Откройте `http://localhost:8080/`. Production размещается в корне репозитория на GitHub Pages. Все пути к ресурсам относительные.

## Проверки

Node.js 20+ и npm нужны только для тестирования:

```sh
npm ci
npm run check
npm run test:media
```

Для `test:media` нужны FFmpeg и FFprobe. Проверки браузеров используют Chromium и WebKit, профили компьютера, Android, iPhone и iPad:

```sh
npx playwright install --with-deps chromium webkit
npm run test:browser
```

Для проверки текста PDF дополнительно нужен `pdftotext` из `poppler-utils`. Тестовый сервер автоматически открывает приложение под префиксом `/salary-increase-portfolio/`, как на GitHub Pages, и поддерживает Range-запросы видео. Это только сервер QA, он не участвует в публикации.

Workflow `Portfolio QA` запускает проверки в Pull Request и сохраняет скриншоты, диагностические traces и PDF в артефакт `portfolio-browser-qa`. Workflow не публикует сайт.

## Видео и PDF

Главный экран занимает весь экран: поверх видео размещены текст и официальный SVG-логотип на полупрозрачном сером стекле. Обложки проектов развёрнуты на всю ширину карточек.

Два предоставленных ролика, начиная с кассового терминала, объединены в последовательность длительностью 23,42 секунды с переходом между сценами и переходом через границу цикла. У web-версий удалён звук, включён MP4 faststart. Для мобильных устройств подготовлен вариант 854×480. Исходники сохранены без изменений.

Повторная подготовка медиа, если установлен FFmpeg:

```sh
bash scripts/build-media.sh
```

При `prefers-reduced-motion` или экономии трафика показывается заставка; анимацию можно запустить явно. Обычный запуск использует `autoplay muted loop playsinline`, без элементов видеоплеера. При запрете autoplay заставка остаётся доступной.

«Сохранить PDF» открывает системную печать браузера. Перед печатью автоматически раскрываются описания всех проектов; после неё восстанавливается выбор читателя. В диалоге печати выберите сохранение в PDF.
