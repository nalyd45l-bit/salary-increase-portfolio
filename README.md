# Мой вклад в LIFE PAY

Профессиональное интерактивное портфолио для обсуждения развития роли и условий оплаты. Доработка существующего репозитория `nalyd45l-bit/salary-increase-portfolio`.

Опубликованная версия: https://nalyd45l-bit.github.io/salary-increase-portfolio/

Этапы доработки оформлены отдельными Pull Request. Читаемость, анимации и постоянный портрет приняты в PR №3. Контактные значки и ссылки приняты в PR №4. По уточнению пользователя в PR №5, ветка `work/restore-original-glass`, возвращены прежние серые прозрачные панели и шапка; улучшенная типографика сохранена. GitHub Pages использует ветку `work/fn36-scroll-story`; после проверки и слияния PR она обновляется до принятого коммита обычным fast-forward. Другие репозитории не изменяются.

## Файлы и запуск

- `index.html` — всё содержание и реальные ссылки. Оно доступно без JavaScript.
- `styles.css` — единая система стилей, адаптивность и печать.
- `app.js` — меню, просмотр изображений, видео, навигация и подготовка PDF.
- `story.js`, `story.css` — сцена ФН‑36, стеклянные компоненты и финальная анимация.
- `proposal.js` — локальная подготовка текста для руководителя без отправки сообщений.
- `portrait.js` — постоянный публичный портрет и необязательная временная замена для PDF.
- `readability.css` — локальный Manrope, контраст текста и плавное появление карточек без потери читаемости.
- `assets/` — официальный SVG LIFE PAY, исходные материалы четырёх видео, скриншоты, портрет и оптимизированные циклы для компьютера и телефона.

Для сайта не нужны сборка, серверная часть, CDN или production-зависимости. Для локального просмотра достаточно статического сервера. Например, из корня репозитория:

```sh
python3 -m http.server 8080
```

Откройте `http://localhost:8080/`. Production размещается в корне репозитория на GitHub Pages. Все пути к ресурсам относительные. Скрипт ambient.js закрепляет четыре тихих видео за окном, выбирает фон для текущего раздела и воспроизводит только активный ролик без элементов управления.

## Проверки

Node.js 20+ и npm нужны только для тестирования:

```sh
npm ci
npm run check
npm run test:media
```

Для `test:media` нужны FFmpeg и FFprobe. Проверки браузеров используют Chromium и WebKit, профили компьютера, Android, iPhone и iPad:

```sh
npx playwright install --with-deps chromium webkit
npm run test:browser
```

Для проверки текста PDF дополнительно нужен `pdftotext` из `poppler-utils`. Тестовый сервер автоматически открывает приложение под префиксом `/salary-increase-portfolio/`, как на GitHub Pages, и поддерживает Range-запросы видео. Это только сервер QA, он не участвует в публикации.

Workflow `Portfolio QA` запускает проверки в Pull Request и сохраняет скриншоты, диагностические traces и PDF в артефакт `portfolio-browser-qa`. Workflow не публикует сайт.

## Видео и PDF

Главный экран занимает весь экран: поверх видео кассы размещены текст и официальный SVG-логотип на полупрозрачном сером стекле. Обложки проектов развёрнуты на всю ширину карточек. Четыре видео сопровождают все разделы: касса — начало, профиль и задачи; ФН‑36 — проекты; оплата — результаты и рынок; личный кабинет — развитие роли и финал. Фоны плавно сменяются при прокрутке, сами ролики воспроизводятся автоматически и при неподвижной странице. Добавлены ещё два ролика: оплата между проектами и результатами, личный кабинет с аналитикой — последней полноэкранной сценой. Карточки проектов и остальные разделы расположены поверх сцены на серых прозрачных стеклянных панелях, все видео воспроизводятся автоматически без кнопок плеера.

Исходные ролики сохранены без изменений. Для главного экрана подготовлен отдельный бесшовный цикл с терминалом, а для ФН‑36 и ещё двух сценариев — отдельные бесшовные MP4. На телефонах web-видео имеет разрешение 854×480. При reduced motion и экономии трафика остаются заставки; отображаются статичные изображения.

Повторная подготовка медиа, если установлен FFmpeg:

```sh
bash scripts/build-media.sh
```

При `prefers-reduced-motion` или экономии трафика показывается заставка; анимация не запускается автоматически. Обычный запуск использует `autoplay muted loop playsinline`, без элементов видеоплеера. При запрете autoplay заставка остаётся доступной.

«Сохранить PDF» открывает системную печать браузера. Перед печатью автоматически раскрываются описания всех проектов; после неё восстанавливается выбор читателя. В диалоге печати выберите сохранение в PDF.
