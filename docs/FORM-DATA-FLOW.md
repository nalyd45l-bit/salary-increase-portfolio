# Форма обсуждения оплаты удалена

По указанию пользователя форма оклада, выбора налогового формата и даты, черновик письма, копирование и резервное поле полностью удалены из сайта 16.11.2026. Скрипт `proposal.js` также удалён. Вместо них размещён раздел «Итоги и профессиональный вклад» с утверждённым пользователем текстом.

Кнопка «Сохранить PDF» в верхней панели продолжает открывать системную печать браузера. Перед печатью раскрываются задачи и проекты, затем восстанавливается состояние читателя. Данные формы сайт больше не собирает.

Публичные ссылки проектов открывают внешние сервисы. Таблица Бота ФН не редактируется сайтом, проверка ФН здесь не запускается. Заявки работодателям и сообщения руководителю не отправляются.

Предыдущая проверка удалённой формы сохранена как исторический материал в [отчёте этапа №10](CONTRIBUTION-QA.md).
